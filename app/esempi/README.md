# Esempi per Circuit Lab

Per riaprire un progetto, scarica il JSON e usa **Apri**. Per importare un CSV, usa **Misura τ** e scegli la scheda adatta ai dati. I due CSV contengono dati sintetici.

| File | Esercizio |
| --- | --- |
| [rc-scarica-dimostrativa.csv](rc-scarica-dimostrativa.csv) | Importa una scarica con incertezze sulla tensione e stima τ. |
| [rc-bode-dimostrativo.csv](rc-bode-dimostrativo.csv) | Importa misure in frequenza e stima il taglio. |
| [rc-con-fit-dimostrativo.json](rc-con-fit-dimostrativo.json) | Riapri un progetto con i dati sintetici e le impostazioni del fit di scarica. |
| [rc-tempo-e-frequenza.json](rc-tempo-e-frequenza.json) | Prova analisi nel tempo e in frequenza nello stesso circuito. |
| [rc-con-misure.json](rc-con-misure.json) | Osserva tensione e corrente con le sonde dell’editor libero. |
| [rc-caricato-slide.json](rc-caricato-slide.json) | Esamina la risposta in frequenza della RC con generatore, cavo e sonda rappresentati nello schema. |
| [invertente-libero.json](invertente-libero.json) | Simula un amplificatore invertente e prova a variare la resistenza di retroazione. |
